
# Online Bookstore SQL Project

## Project Overview
This project analyzes an online bookstore's data using SQL.
It focuses on books, customers, orders, sales, and inventory.

## Dataset
The project uses three CSV files:
- Books.csv
- Customers.csv
- Orders.csv

## SQL Concepts Used
- SELECT and WHERE
- ORDER BY and GROUP BY
- Aggregate Functions
- JOIN Operations
- Subqueries

## Key Queries
- Retrieve books by genre
- Find books published after 1950
- List customers from Canada
- Calculate total stock and revenue
- Find the most expensive book
- Identify frequently ordered books
- Analyze sales by genre and author
- Calculate remaining stock after orders
